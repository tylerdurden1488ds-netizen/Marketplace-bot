# Creative Concept

На основе анализа товара предложи концепцию карточки:
- фон;
- композиция;
- главный заголовок;
- дополнительные тексты;
- преимущества;
- типографика;
- визуальные элементы;
- освещение;
- цветовая палитра.

Сначала сформируй понятную концепцию, затем финальный image-generation prompt.
