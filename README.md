# Marketplace Card Bot

Telegram-бот для создания карточек товаров для Wildberries, Ozon, Avito и Яндекс Маркета.

## Переменные окружения

В Bothost добавь:

- `BOT_TOKEN` — токен Telegram-бота от BotFather
- `GEMINI_API_KEY` — API-ключ Gemini
- `ADMIN_ID` — необязательно, Telegram ID администратора

Секреты не хранятся в GitHub.

## Режимы

1. ✍️ Я задаю дизайн — пользователь отправляет фото и описание желаемого фона/текста.
2. 🤖 ИИ придумывает дизайн — пользователь отправляет только фото, а ИИ предлагает концепцию.

## Архитектура

- `bot/` — Telegram-интерфейс
- `ai/` — Gemini и сборка промптов
- `skills/` — библиотека правил и промптов
- `prompts/` — системные шаблоны
