INFOGRAPHIC

Карточка должна быстро объяснять покупателю товар.

Структура:

1. Главный заголовок.
2. Главное преимущество.
3. 2-4 коротких преимущества.
4. При необходимости небольшие визуальные маркеры.

Используй:

- короткие фразы;
- понятные иконки;
- аккуратные блоки;
- хорошее расстояние между элементами.

Не придумывай технические характеристики,
которых нет в исходных данных.
